# Mert Kaya — Beyond the Court

Personal portfolio: a volleyball-themed interactive "quest" that ends in a developer portfolio.
Built with React, TypeScript, Vite and Tailwind CSS. (Full README comes with the first release.)

## Scripts

| Command           | What it does                                  |
| ----------------- | --------------------------------------------- |
| `npm run dev`     | Start the dev server at http://localhost:5173 |
| `npm run build`   | Type-check and build for production (`dist/`) |
| `npm run preview` | Serve the production build locally            |
| `npm run lint`    | Lint with Oxlint                              |
| `npm run format`  | Format all files with Prettier                |
